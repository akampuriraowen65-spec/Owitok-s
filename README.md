# Owitok

Owitok is a Version 1 short-video web/PWA foundation.

## Included
- Vertical video feed with swipe/scroll snap
- Local video upload
- Tap to pause/play
- Local likes, saves and comments
- Search of locally stored videos
- Profile and settings screens
- Camera preview
- PWA manifest and service worker

## Important
Version 1 stores video data locally on the device. It does not yet provide global accounts, followers, comments or cloud video storage.

## GitHub
Put the actual project files in the repository root. Do not leave the project only inside ZIP archives.

## Next backend stage
